# 결과물 안내

## 사용자가 보는 최종본

`모난이/` 폴더에 확정 캐릭터, 제작 기준, 1화의 1080 PNG 5장·전체 미리보기·1920 ZIP이 있습니다.

## 에이전트가 읽는 현재 정보

- `monani/series.json`: 확정 스타일·캐릭터·공통 설정
- `monani/episodes/rest-001/episode.json`: 콘티·생성 기록·배치·검수·승인·최종 파일
- `monani/episodes/rest-001/history.jsonl`: 변경 이벤트 누적 기록
- `monani/assets/`: 실제 참조 이미지 등. 해시 기반 이름으로 같은 파일을 중복 저장하지 않습니다.

새 작업은 이 두 JSON을 먼저 읽습니다. 이전 ZIP을 풀 필요가 없습니다. JSON 직접 수정 대신 저장소 tool의 save_series/save_revision을 사용합니다. 최종본을 수정하면 같은 에피소드의 현재 정보와 이력을 갱신하고 새 PNG를 저장합니다.

## 이전 제작 기록

`_archive/legacy-v1-2026-10-19.zip`은 기존 분산 JSON·시안·원본·출력을 원래 경로로 보관한 파일입니다. 바이트 검증 후 이전 폴더를 압축 보관했습니다. 현재 에피소드는 이 보관본 없이도 검증 가능합니다. migration.source_root는 이전 당시의 위치를 남긴 역사적 정보입니다.

과거 버전 확인이 필요한 경우에만 별도 작업 디렉터리에 압축을 풉니다. ZIP 내부 최상위는 outputs입니다. 기존 현재 파일 위에 풀지 않습니다.
