# 모난이 1화 — 조금 있다 굴러가자

## 시리즈 방향

작고 하찮은 돌멩이의 일상 공감 + 힐링툰. 훈계하거나 해결책을 주기보다, 같이 쉬어 주는 작은 행동으로 위로한다. 캐릭터는 살짝 모나 잘 구르지 못하는 조약돌 ‘모난이’. 점눈과 짧은 입, 가느다란 짧은 팔다리로 표현한다.

## 5컷 콘티

| 컷 | 장면 | 대사 |
| --- | --- | --- |
| 1 | 낮은 언덕 길. 둥근 돌들이 데굴데굴 지나간다. 화면 왼쪽 아래의 작은 모난이는 가만히 바라본다. | 모난이: 다들 잘 굴러가네. |

| 3 | 조금 기울던 모난이가 철푸덕 엎어진다. 무리한 슬픔 대신 멍한 표정과 짧은 팔다리로 허탈함을 표현한다. | 모난이: 오늘은 안 되겠다. |
| 4 | 같은 자리에 둥근 돌 하나가 굴러와 멈춘다. 나뭇잎 그늘이 두 돌 위로 드리운다. 친구는 모난이에게 조언하지 않고 옆에 앉는다. | 친구: 여기 그늘 좋다. |
| 5 | 조금 더 넓은 구도. 두 돌이 그늘 아래 나란히 앉고 작은 잎이 바람에 흔들린다. 모난이의 입이 아주 조금 올라간다. | 모난이: 조금 있다 굴러가자. |

## 표현 규칙

- 상단 여백에 글자를 직접 배치한다. 말풍선 테두리·꼬리는 기본으로 사용하지 않는다.
- 검은 외곽선, 제한된 평면색, 옅은 배경이라는 기존 승인 스타일을 재사용한다.
- 돌의 표면 균열·근육·손가락 등 복잡한 묘사는 넣지 않는다.
- 친구는 얼굴 없는 소품이 아니라 모난이와 같은 단순한 돌 캐릭터 문법을 사용한다. 둥근 윤곽으로 구별한다.
- 결말에 ‘쉬어도 괜찮아’ 같은 별도 교훈 문장을 추가하지 않는다.

## 진행 상태

- 이야기와 캐릭터 방향: 사용자의 ‘ㅇㅇ 그렇게 해줘’에 따라 확정.
- 실제 캐릭터 시트: 생성 후 시각 확인 대상. 텍스트 방향 승인을 실제 이미지 승인으로 대체하지 않는다.
- 개별 5컷 그림·식자: 캐릭터 시트 확인 후 진행.
