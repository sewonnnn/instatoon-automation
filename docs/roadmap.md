# 개발 로드맵

## 초기 결정 사항

- [ ] 인스타툰 주제와 타깃 독자
- [ ] 고정 캐릭터, 화풍, 말투
- [ ] 에피소드당 컷 수와 이미지 규격
- [ ] 대본 및 이미지 생성 서비스
- [ ] 실행 방식: CLI, 웹 화면, 또는 작업 스케줄러
- [ ] 게시용 파일 내보내기와 계정 게시 연동의 우선순위

## 1단계: 기획과 대본

- [ ] 주제 입력으로 에피소드 초안 생성
- [ ] 컷별 장면 설명, 대사, 내레이션 구조 정의
- [ ] 초안 저장 및 수정

## 2단계: 이미지 제작

- [ ] 캐릭터 및 화풍 참조 관리
- [ ] 컷별 이미지 생성
- [ ] 선택한 컷만 재생성
- [ ] 말풍선 및 텍스트 합성

## 3단계: 게시물 준비

- [ ] 컷 순서 및 이미지 규격 검증
- [ ] 캡션과 해시태그 생성
- [ ] 게시용 이미지와 문구 내보내기
- [ ] 게시 전 사용자 검수

## 4단계: 운영 자동화

- [ ] 공식 API의 지원 범위와 계정 요건 확인 후 게시 연동
- [ ] 예약 작업 및 실행 기록
- [ ] 실패한 작업 재시도와 중복 게시 방지
