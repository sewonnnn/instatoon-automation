### 전체 흐름 (PDF 「[인스타툰]」 기준)

text

```
[PDF 1. 기획 및 설계]
① 스타일 팩 선택
② 캐릭터 정하기 → 캐릭터 시트(정면/3/4 측면/주요 표정) 생성
                                                       ✅ 승인 (시리즈 전체 공유)
③ 주제 정하기 (경로 A / 경로 B) → 후보 제시 → 선택

[PDF 3. 콘티 구성]
④ 1차 콘티 (텍스트 콘티): 컷 분할, 인물 배치, 말풍선
   → 자동 QA (1차 검토 요소) → 자동 수정                 ✅ 승인 (콘티)
⑤ 2차 콘티 (인물 묘사): 컷 생성 (초안 모델, 말풍선 없이, 캐릭터 시트 참조)
   → 자동 QA (2차 검토 요소) + 캐릭터 일치 → 미달 컷 재생성
   → "대사 없이 표현 가능" 판정 시 콘티 수정 제안
⑥ 말풍선 레이아웃 (Z자 시선 규칙) + 한글 렌더링 (코드)
⑦ 미리보기 (컷 재생성, 말풍선 직접 이동, 대사 수정)    ✅ 승인 (최종)

[PDF 4. 깔끔하게 선 정리하기]
⑧ 승인 컷 최종 품질 생성 (스타일 팩 펜선 기준 적용)
   → 1920×1920 + 1080×1080 PNG + AI 생성물 표시

[후순위]
⑨ 인스타 연동 댓글 분석 → 소재 추천

```

###  ② 캐릭터 정하기 (PDF)


| 종류  | 세부              | 특징                            |
| --- | --------------- | ----------------------------- |
| 사람  | 2등신             | 디테일 살리지 않음, 하찮고 귀여운 스타일       |
| 사람  | 4\~5등신          | 2등신보다 디테일 있음, 감성적·차분한 스토리에 적합 |
| 동물  | 얼굴만 동물 / 몸까지 동물 |                               |
| 무생물 | 먼지, 밥풀, 돌멩이 등   |                               |


###  ③ 주제 정하기 (PDF, 마인드맵 활용)

- **경로 A**: '나'에 대한 정보(성격, 좋아하는 것, 싫어하는 것) → 마인드맵 → 여러 경우의 수로 주제 도출
- **경로 B**: '소재로 사용하면 좋을 것 같은 단어' 중심 → 관련 키워드 뽑아냄 → 경우의 수로 주제 도출 (예: 사랑 → 행복 → 커플 → 데이트 → 맛집)
- **후순위**: 인스타 연동, 사용자 인스타툰 댓글(좋아요 많은 n개) 반응 분석 → 공감·재미 분류 → 소재 추천
  1. 공감 O, 재미 O → 모두 충족
  2. 공감 O, 재미 X
  3. 공감 X, 재미 O
  4. 공감 X, 재미 X → 보강 또는 다른 아이디어의 영감 용도

###  ④ 1차 콘티 (PDF)

- 인스타툰의 특징을 살린다
- 단편: 10컷 안에 스토리 완결 / 장편: 10컷 안에 다음 화가 궁금하게
- 순서에 맞게 컷 분할(최대 10개) 후 인물 및 말풍선 배치
- 독자가 어떤 순서로 봐주길 원하는지 생각하며 배치
- 왼쪽 → 오른쪽 → 왼쪽 → 오른쪽 **Z자 시선**이 자연스러움
- 순서뿐 아니라 인물 크기, 말풍선 크기도 중요한 영향

예시 (등장인물 = 씨큐, 헨디 / 주제 = 뾰루지):

1. 얼굴에 뾰루지가 나 속상해하는 씨큐, 그걸 본 헨디
2. 씨큐의 뾰루지를 터뜨리려는 헨디
3. 샤워부터 하고 오겠다는 씨큐
4. 샤워를 끝마치고 나온 씨큐, 그리고 사라진 뾰루지
5. 울부짖는 헨디, 억울해하는 씨큐
6. 헨디 얼굴에도 뾰루지 발견, 하지만 헨디 것은 짜면 안 됨

### ⑤ 2차 콘티 (PDF)

- 1차 콘티를 바탕으로 캐릭터 묘사를 더 진행
- 이야기 흐름상 배경 묘사가 불필요하면 표정·머리카락·이목구비 정도만 묘사 후 마무리 (`background: none`)
- 참조 입력: **원본 캐릭터 시트 + 스타일 팩 기준 이미지** (직전 컷 참조 금지)

###  출력 규격 (PDF)


| 용도                 | 크기                       | 해상도          |
| ------------------ | ------------------------ | ------------ |
| 인스타그램 정사각형(1:1) 노출 | 1080×1080 px             | 웹 전용 약 72dpi |
| 책·영상 등 확장 계획 시 권장  | 1920×1920 px (약 16.26cm) | 인쇄물 300dpi   |


내부 작업은 1920 기준, 출력은 두 크기 모두.
