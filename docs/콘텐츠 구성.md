# 콘텐츠 구성 메모

## 시리즈 방향

특정 주인공이 매번 등장하는 방식 대신, **비슷한 그림체의 다양한 하찮은 사물들이 여러 번 재등장하는 공감+힐링툰**으로 구성한다.

- 에피소드마다 이야기와 감정에 어울리는 사물을 주인공으로 선택한다.
- 기존 사물이 어울리면 다시 등장시키고, 필요한 경우 새로운 사물을 만든다.
- 사물끼리 같은 에피소드에 등장하며 관계를 맺어도 좋다.
- 모든 사물에 이름이나 복잡한 설정을 붙일 필요는 없다.
- 재등장하는 사물의 외형은 이전 모습과 일관되게 유지한다.
- 기존 모난이 1화 「조금 있다 굴러가자」는 이 방향의 첫 이야기로 활용할 수 있다.

## 공통 그림체

- 흰 배경
- 보슬보슬하고 구불구불한 손그림 테두리
- 점눈, 짧은 입, 짧고 단순한 팔다리
- 작고 하찮은 느낌의 형태와 몸짓
- 사물의 특성에 맞는 차분한 색상: 모든 사물을 회색으로 고정하지 않는다.
- 넉넉한 여백과 말풍선 없이 직접 배치하는 대사

## 이야기 톤

일상의 작은 피로와 서툼에 공감하고, 작은 행동이나 함께 있는 장면으로 위로한다. 교훈이나 해결책을 설명하기보다 “나만 그런 게 아니네”라는 느낌을 준다.

## 사물과 소재 예시

아래는 확정 캐릭터 목록이 아닌 소재 후보다.

| 사물 | 어울리는 감정·상황 |
| --- | --- |
| 돌멩이 | 남들과 속도를 비교하는 날 |
| 구겨진 종이 | 하루가 뜻대로 풀리지 않은 날 |
| 스펀지 | 남의 기분까지 받아주느라 지친 날 |
| 양말 | 혼자인 것 같다가 뜻밖의 짝을 만나는 날 |
| 종이컵 | 작은 일에도 뿌듯해지는 날 |

## 제작과 관리 아이디어

이야기 먼저 정하기 → 감정에 어울리는 사물 고르기 → 기존 사물 재사용 또는 새 사물 제작.

스타일은 시리즈 공통 설정으로 관리하고, 캐릭터는 필요할 때 선택하는 사물 목록으로 관리한다. 이 문서는 방향 메모이며, 현재 시리즈 설정이나 제작 코드를 변경한 것은 아니다.
