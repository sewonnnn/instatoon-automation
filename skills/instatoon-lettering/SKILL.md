# 인스타툰 식자와 출력

## 입력과 참조

QA를 통과한 그림, 승인 콘티의 텍스트, 스타일의 식자 규칙을 확인한다. [식자 기준](../../references/lettering.md), [데이터 계약](../../references/contracts.md), [tool 현황](../../references/tools.md), [QA](../../references/qa.md)를 읽는다.

## 절차

1. 실제 그림을 보고 인물·표정·중요 소품을 피하는 말풍선 영역과 꼬리를 정한다. 좌표는 1920 기준이다.
2. 사용 가능한 한글 폰트를 확인하고 실제 글자 폭으로 줄바꿈·크기를 정한다. 대사 변경이 필요하면 콘티 수정으로 돌리고 임의 삭제하지 않는다.
3. 코드 기반 합성 도구로 말풍선·대사·내레이션·효과음과 합의된 AI 생성물 표시를 렌더링한다.
4. 개별 컷과 전체 미리보기를 만들고 1080 축소본까지 검토한다. 레이아웃 변경으로 해결 가능한 문제는 그림을 다시 생성하지 않는다.
5. QA를 통과한 최종 미리보기를 제시하고 사용자 승인을 받는다. 승인 대상에는 두 출력 크기의 결과와 순서가 포함된다.
6. 승인된 파일을 두 크기의 PNG로 내보내고 episode.json의 exports에 순서·버전·해시·승인 연결을 저장한다. 출력 시 새 이미지를 생성하거나 대사를 바꾸지 않는다.

## 완료 조건

`episode.json` 안의 layout·QA·exports·승인과 두 크기 PNG가 연결되어 있다. 합성 tool이 없으면 배치 명세까지 작성하고 렌더링 미완료를 알린다. 텍스트 프롬프트로 만든 그림을 코드 식자 완료로 대체하지 않는다.

## 저장 방식

[데이터 계약](../../references/contracts.md)의 v2를 따른다. 현재 정보는 series.json·episode.json, 에피소드 변경 이력은 history.jsonl로 관리한다. 컷별·단계별 JSON이나 매 수정 시 전체 snapshot을 추가하지 않는다.
