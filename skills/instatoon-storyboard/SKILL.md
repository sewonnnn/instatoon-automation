# 인스타툰 콘티

## 입력과 참조

기획, 캐릭터·스타일 버전, 기존 콘티를 확인한다. [콘티 기준](../../references/storyboard.md), [데이터 계약](../../references/contracts.md), [QA](../../references/qa.md)를 읽는다. 수정 시 [진행 규칙](../../references/workflow.md)을 확인한다.

## 절차

1. 각 컷이 독자에게 새로 알려주는 사건이나 감정을 먼저 정한다. 단편은 10컷 이내에 완결하고 연재는 다음 화 질문을 남긴다.
2. 컷마다 등장인물, 행동·표정, 구도, 배경 필요성, 인물 위치와 텍스트 읽는 순서를 작성한다.
3. 고정 `panel_id`와 `text_id`를 부여한다. 대사·내레이션·효과음과 화자를 분리하고 대사가 없어도 텍스트 목록을 빈 배열로 기록한다.
4. 의미·읽는 흐름·대사 밀도를 검토하고 수정한다. 아직 그림이 없으므로 실제 말풍선 충돌과 공간 QA는 예정 검사로 남긴다.
5. 컷별 장면과 대사를 읽기 쉬운 목록으로 제시해 승인받고 `episode.json`의 documents.storyboard와 QA를 갱신한다.

## 완료 조건

그림을 만드는 데 필요한 장면과 글자 합성에 필요한 텍스트가 분리되어 있고, 주요 QA 문제를 해결한 콘티가 승인되었다. 콘티만 요청한 경우 미확정 캐릭터 역할을 사용할 수 있으나 실제 컷 생성 전에는 승인된 자원 ID로 연결해야 한다.

## 저장 방식

[데이터 계약](../../references/contracts.md)의 v2를 따른다. 현재 정보는 series.json·episode.json, 에피소드 변경 이력은 history.jsonl로 관리한다. 컷별·단계별 JSON이나 매 수정 시 전체 snapshot을 추가하지 않는다.
