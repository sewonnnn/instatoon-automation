# 인스타툰 스타일

## 입력과 참조

주제·독자·분위기와 기존 스타일을 확인한다. 사용자 레퍼런스는 선택 입력이다. [스타일 기준](../../references/style.md), [데이터 계약](../../references/contracts.md), [tool 현황](../../references/tools.md)을 읽는다. 검토할 때 [QA](../../references/qa.md)의 스타일 항목을 읽는다.

## 절차

1. 사용 가능한 검색 도구로 관련 시각 레퍼런스를 찾고 실제 이미지와 원문 출처를 확인한다. 분석할 수 없는 이미지를 분석했다고 기록하지 않는다.
2. 선·색·형태·배경·식자에서 필요한 특징을 추출해 2~3개 방향으로 정리한다. 검색 이미지를 완성한 자체 샘플로 취급하지 않는다.
3. 같은 비교용 장면에 각 방향을 적용한 샘플을 생성한다. 이미지 생성 도구가 없다면 텍스트 후보와 검색 결과까지 저장하고 시각 샘플 제작이 미완료임을 알린다.
4. QA 후 후보 이미지, 차이, 어울리는 이야기, 출처를 보여주고 선택·수정을 받는다.
5. 샘플 이미지를 저장하고 선택한 스타일 규칙·출처·QA·승인은 `series.json`의 style에 넣는다.

## 완료 조건

선택한 샘플과 실행 가능한 표현 규칙이 일치하고 사용자 승인이 해당 버전에 연결되어 있다. 캐릭터의 종류·등신·고유 특징은 확정하지 않는다. 샘플 인물은 비교용이며 캐릭터 스킬에 승인된 인물로 넘기지 않는다.

## 저장 방식

[데이터 계약](../../references/contracts.md)의 v2를 따른다. 현재 정보는 series.json·episode.json, 에피소드 변경 이력은 history.jsonl로 관리한다. 컷별·단계별 JSON이나 매 수정 시 전체 snapshot을 추가하지 않는다.
