# 인스타툰 그림

## 입력과 참조

승인된 콘티·스타일·캐릭터 시트와 대상 컷을 확인한다. [그림 기준](../../references/drawing.md), [데이터 계약](../../references/contracts.md), [tool 현황](../../references/tools.md), [QA](../../references/qa.md)를 읽는다.

## 절차

1. 요청 컷의 입력 버전과 기존 결과를 비교한다. 완료된 컷은 입력이 유효하면 재사용한다.
2. 장면·행동·표정·구도, 글자가 들어갈 공간, 배경 필요성을 프롬프트로 구성한다. 원본 캐릭터 시트와 승인된 스타일 샘플을 직접 참조하고 글자·말풍선은 제외한다.
3. 실제 생성 도구로 컷을 제작하고 사용한 입력·참조·생성 설정·파일을 기록한다. 이전 컷을 캐릭터 기준으로 사용하지 않는다.
4. 생성된 그림을 직접 보고 캐릭터 일치와 장면 전달을 검토한다. 실패 이유를 좁혀 해당 컷만 수정한다.
5. 필요한 최종 품질 처리를 수행하고 내용이 바뀌면 다시 검토한다. 대사를 없애거나 사건을 바꾸는 제안은 콘티 변경으로 돌린다.
6. `art.png`를 저장하고 생성 기록·QA는 `episode.json` 안에 넣는다. 원본 크기와 리사이즈·업스케일 이력을 구분한다.

## 완료 조건

대상 컷의 그림 QA가 통과하고 글자 없는 최종 그림이 식자에 전달될 준비가 되어 있다. 생성·시각 검사 기능이 없으면 프롬프트 준비 또는 검사 불가로 기록하며 이미지 제작 완료를 선언하지 않는다.

## 저장 방식

[데이터 계약](../../references/contracts.md)의 v2를 따른다. 현재 정보는 series.json·episode.json, 에피소드 변경 이력은 history.jsonl로 관리한다. 컷별·단계별 JSON이나 매 수정 시 전체 snapshot을 추가하지 않는다.
