# 인스타툰 캐릭터

## 입력과 참조

승인된 스타일 버전, 캐릭터 설명 또는 이야기에서 필요한 역할, 기존 시트를 확인한다. [캐릭터 기준](../../references/character.md), [데이터 계약](../../references/contracts.md), [tool 현황](../../references/tools.md)을 읽고 [QA](../../references/qa.md)의 캐릭터 항목을 적용한다.

## 절차

1. 승인된 스타일이 없으면 전체 진행 스킬에 스타일 준비를 요청한다. 단독으로 외형 아이디어만 요청했다면 텍스트 제안까지만 작성하고 시트 완료로 기록하지 않는다.
2. 사람·동물·무생물 종류, 비율, 실루엣, 얼굴, 색, 의상·소품의 고정 특징을 정리한다. 정보가 부족하면 캐릭터 후보를 직접 제안한다.
3. 정면·3/4 시점과 이야기에서 필요한 주요 표정이 있는 시트를 생성한다. 같은 인물의 얼굴·색·비율이 유지되는지 비교한다.
4. 명세와 시트를 함께 보여주고 수정·승인을 받는다. 변경은 새 캐릭터 버전으로 저장한다.
5. `sheet.png`를 저장하고 명세·사용 스타일·QA·승인은 `series.json`의 characters에 넣는다.

## 완료 조건

시트가 명세와 일치하고 각 시점·표정에서 동일 인물로 인식되며 사용자 승인이 있다. 그림 스킬에는 승인된 원본 시트를 전달한다. 다른 에피소드에 새 캐릭터 버전을 소급 적용하지 않는다.

## 저장 방식

[데이터 계약](../../references/contracts.md)의 v2를 따른다. 현재 정보는 series.json·episode.json, 에피소드 변경 이력은 history.jsonl로 관리한다. 컷별·단계별 JSON이나 매 수정 시 전체 snapshot을 추가하지 않는다.
