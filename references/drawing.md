# 컷 이미지 제작 기준

생성 입력은 승인된 컷 설명, 원본 캐릭터 시트, 승인된 스타일 샘플이다. 프롬프트에는 등장인물별 행동·표정, 인물 사이 관계, 카메라 구도, 배경과 소품, 글자를 둘 여백을 명확히 적는다. 이미지에 대사·효과음·말풍선을 생성하지 않는다.

참조 제한 때문에 필요한 시트를 모두 전달할 수 없으면 도구의 실제 제한과 대안을 확인한다. 참조를 빠뜨리고 일관성이 보장된다고 보고하지 않는다. 특정 컷의 수정에는 해당 컷 원본을 편집 대상으로 쓸 수 있지만 캐릭터 기준은 원본 시트로 유지한다.

검토는 장면 의도 → 인물 정체성 → 행동·표정 → 구도·배경 → 선과 불필요한 글자 순으로 한다. 문제 원인을 기록하고 “더 좋게” 대신 “오른쪽 인물의 귀 모양을 시트와 맞춤”처럼 수정 범위를 좁힌다.

최종 품질 처리는 필요할 때만 수행한다. 리사이즈·업스케일·생성 편집을 구분하고 원본 크기와 실제 처리 이력을 기록한다. 생성 편집으로 내용이 달라졌다면 다시 그림 QA를 수행한다. 처리 후 식자로 넘기며 최종 승인 이후 새로 생성하지 않는다.
