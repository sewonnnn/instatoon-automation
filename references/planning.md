# 기획 기준

사용자가 제공한 경험·성격·좋아하거나 싫어하는 것에서 구체적 사건을 찾거나, 키워드의 연상을 통해 소재를 만든다. 예를 들어 월요일 → 출근 → 커피 → 잠 깨기 → 커피를 기다리며 조는 상황으로 좁힌다. 사용자의 실제 경험이라고 말하지 않은 사건은 창작 제안으로 표시한다.

후보는 제목, 한 줄 사건, 독자의 공감 지점, 재미 또는 감정 전환, 결말로 비교한다. 표현만 다른 후보를 늘리지 않는다. 단편은 작은 사건 하나를 완결하고 연재는 현재 화의 변화와 다음 화의 질문을 함께 만든다.

초기 4~6컷은 제안값이고 사용자 분량을 우선하되 제품 범위는 최대 10컷이다. 정보 전달형이면 사실 주장에 필요한 출처를 확인하고, 허구의 공감 장면과 사실 정보를 구분한다. 요청이 구체적이면 그대로 기획하고 불필요한 소재 투표를 만들지 않는다.

좋은 기획 예: 월요일 커피로 잠을 깨려던 사람이 커피가 식기를 기다리다 잠든다. 중심 행동과 결말이 그림으로 전달된다.

보강이 필요한 기획 예: 월요일은 힘들다. 감정만 있고 사건이 없으므로 구체적인 행동과 변화가 필요하다.
